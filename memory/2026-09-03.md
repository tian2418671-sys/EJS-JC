## 关键技术决策（踩坑记录）
1. **QThread 生命周期**：`finished → 先置 self.worker=None 再 connect(deleteLater)`，顺序必须保持，否则 Python 引用悬垂 → RuntimeError 被 Qt 吞掉 → 事件循环永不退出（表现为超时挂死）
2. **跨线程 SQLite**：sqlite3.connect(check_same_thread=False)，SQLite serialized 模式允许；读写顺序由 Qt 队列信号保证
3. **next_error_id**：max(表内后缀, sqlite_sequence 水位)+1，DELETE 清表后编号不回退
4. **PySide6 安装**：约 150MB，`pip install` 超时阈值为 300s 不够，需后台安装；PowerShell 管道把 pip stderr notice 变 NativeCommandError（returncode 1 假阳性）
