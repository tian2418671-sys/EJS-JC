# 2026-09-04 — Phase 1 后期：GUI 细节打磨完成

## 交付内容
1. **应用图标**：新增 `scripts/gen_icon.py`（纯 numpy+stdlib 生成，无外部依赖），产出
   `resources/icon.png`（256px）+ `resources/icon.ico`（16/32/48/64/256 五档，PNG 内嵌）。
   - `app.py`：新增 `_resource_path()`（兼容 dev 与 PyInstaller frozen 的 `sys._MEIPASS`），`setWindowIcon`。
   - `build.spec`：`icon="resources/icon.ico"`（原为 `if False` 关闭），`datas` 追加 `("resources", "resources")`。
2. **报告导出**：新增 `mvu_lint/utils/report_exporter.py`（Qt-free，纯逻辑）。
   - `export_csv`（utf-8-sig BOM，Excel 兼容）、`export_markdown`、`export_html`（自包含深色主题，含转义防注入）。
   - 结果按 严重级别→error_id 数字感知排序。
3. **最近打开列表**：`MainWindow` 用 `QSettings("MvuEjsLinter")` 持久化最近 5 个 ZIP，文件菜单「最近打开」子菜单 + 清空。
4. **错误状态管理**：
   - `DatabaseManager.set_error_status(error_id, status)`（返回是否命中 1 行）。
   - `AppController.set_error_status()` 转发。
   - `ReportPanel` 右键上下文菜单「标记为待处理/已修复/已忽略」，状态列中文显示（待处理/已修复/已忽略），发 `status_changed` 信号由 MainWindow 写回 DB。

## 验证结果
- 单元测试：**50 passed**（39 旧 + 6 导出 + 2 DB 状态 + 3 GUI 状态/导出）。
- 重新打包 `dist\MvuEjsLinter.exe` 通过；`--verify-binaries` 全部通过；冒烟存活 8s。
- 归档确认 `resources/icon.png` + `resources/icon.ico` 已收集。

## 技术要点
- ICO 用「PNG 内嵌」格式（Vista+ 支持），无需第三方库；256px 档的 width/height 字节填 0。
- PySide6 `QSettings.value(key, default, type=list)` 必须显式传 `type=list`，否则返回 str 导致解包错误。
- `report_exporter` 排序用 error_id 的数字部分做 int 比较，避免 "EJS-0010" < "EJS-0002" 的字典序陷阱。
- HTML 导出对 file_path/message/suggestion 做 `html.escape`，防止角色卡内容注入 `<script>`。
